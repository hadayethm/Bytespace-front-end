# ByteSpace (front-end)
Next.js 14 (App Router) + React + TypeScript + Tailwind CSS.

    npm install
    npm run dev   # http://localhost:3000

Routes: `/` Home · `/courses` Search · `/courses/1` Details (About/Lessons/Reviews tabs) · `/creators/1` Creator · `/login` · `/register` · any unknown URL → 404.
Mock data: `lib/data.ts`. Images use picsum.photos placeholders — replace with your own.
